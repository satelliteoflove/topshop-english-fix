Every edited string in the executable, followed to every place the game uses it. 2026-10-27.

Each of the 114 edits to the executable's text was traced through the code to each use site. The question every time: what's on screen, and what does the game actually do, at the moment the line appears? Description strings were checked against the code that carries out the effect, not against the original wording.

Scope

This covers the executable's text. The event card and story scene edits weren't re-audited: those were reviewed one screen at a time in play order, with each event's effect checked in the code, and several were seen in the emulator. Two related checks now run in every build: an edit can't be longer than its original where the code copies a fixed number of bytes, and an edit has to match the original text it replaces.

Side note for the bug pass: the points exchange belongs to player 1 only. Its effects use "player 1" and "everyone else" rather than the current player. That matches the wording, because only player 1 can open the menu. Item 47 (Level 4 upgrade) also takes over any rival stores in the area it fills. The description doesn't say so, and there's no room to.
